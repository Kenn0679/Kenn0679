## 🚀 What I'm working on

At Vizera, I made these product flows more predictable:

- **Video generation:** the Generate button stays disabled for the whole run and the progress card survives client timeouts, so users can't start duplicate jobs or lose track of a running one.
- **Image extend:** the panel sliders and canvas drag handles share one padding value, so the preview, the saved size and the AI request always match.
- **Sign-up and password reset:** one shared password-rules schema with a live checklist, reused on both pages across 5 languages.
- **Boards:** the selected board lives in the URL without dropping other query parameters, so shared links and refreshes open the right board.
